## Problems encountered

- **EXE 로그 미기록 원인 추적**: EXE가 실행되는 것처럼 보이지만(6초 생존) 로그를 쓰지 않는 현상 → 임포트 시간(4.4초)이 대부분을 차지하고, `run()`이 호출되지 않아 "Tree-Size started" 메시지가 기록되지 않음을 단계적 probe 스크립트로 확인.
- **headless 환경 테스트의 한계**: `subprocess.Popen`으로 EXE를 실행하면 프로세스는 살아있지만 창이 보이지 않아 정상/비정상 판별이 어려움 → 로그 파일 증가 여부를 기준 지표로 활용.
- **스펙 파일 git 미추적**: `.gitignore`의 `build/` 패턴이 스펙 파일도 제외 → `!build/*.spec` 예외 추가로 해결.
