> **문서 버전**: 0.1 (초안)
> **작성일**: 2026-05-06
> **작성자**: kdkim2000@samsung.com
> **상태**: Draft

---

## 1. 제품 개요

Windows PC에서 폴더와 파일의 디스크 사용량을 시각적으로 분석하는 데스크톱 GUI 애플리케이션. 상용 도구인 **TreeSize Free / WizTree / WinDirStat**의 오픈 핵심 기능을 Python 기반으로 재구현한다.

* **제품명**: Tree-Size (tentative)
* **플랫폼**: Windows 10 / Windows 11 (x64)
* **배포 형태**: PyInstaller 단일 실행 파일 (`tree-size.exe`)
* **라이선스 정책**: 내부 사용 (배포 시 PySide6의 LGPL 조건 준수)

---

## 2. 목표 및 배경

### 2.1 문제

* Windows 탐색기는 폴더의 누적 용량을 실시간으로 보여주지 않음 → "어디서 디스크가 차고 있는지" 파악이 어려움.
* 기존 상용 도구는 폐쇄적이거나, 광고/유료 기능 제한이 있음.
* 사내 환경에서 신뢰 가능한 오픈 솔루션이 필요.

### 2.2 목표

| 목표 | 측정 지표 |
|------|-----------|
| 빠른 스캔 성능 | 100만 파일(약 500GB) 기준 5분 이내 |
| UI 무응답 없음 | 스캔 중에도 60fps 수준 인터랙션 유지 |
| 정확한 용량 표시 | 논리 크기 + 실제 디스크 할당 크기 모두 제공 |
| 단일 EXE 배포 | 사용자 환경에 Python 설치 불요 |

### 2.3 비목표 (Non-Goals)

* 네트워크 드라이브의 정밀 분석(베스트 에포트만 지원).
* macOS / Linux 지원.
* 클라우드 스토리지(OneDrive, Dropbox)의 미동기화 파일 분석.
* 디스크 클린업 자동화 / 중복 파일 제거 엔진(별도 툴 영역).

## 6. 기술 스택 결정사항 (확정)

| 영역 | 선택 | 결정 근거 |
|------|------|----------|
| 언어 | Python 3.11+ | venv 이미 구성됨, 풍부한 OS 라이브러리 |
| GUI 프레임워크 | **PySide6 (Qt 6)** | LGPL 라이선스로 상용 배포 자유, 고성능 위젯, `QFileSystemModel` 등 검증된 자산 |
| 차트 | **PyQtGraph** 또는 Qt Charts | 네이티브 Qt 통합, 대용량 데이터 렌더링에 강함 |
| 비동기/병렬 | `QThreadPool` + `QRunnable` (UI 스레드 신호 분리) | Qt 표준 패턴, 시그널/슬롯으로 스레드 안전한 UI 갱신 |
| 캐시 | **SQLite (`sqlite3` 표준 라이브러리)** | 외부 의존성 없음, WAL 모드로 동시 R/W 가능 |
| 파일 I/O | `os.scandir` + Win32 API (`ctypes`) for compressed/allocation size | `os.scandir`이 `stat`보다 빠름, NTFS 메타는 Win32 호출 |
| 로깅 | `logging` + `RotatingFileHandler` | 표준 라이브러리 |
| 테스트 | `pytest`, `pytest-qt` | Qt UI 컴포넌트 단위 테스트 가능 |
| 코드 품질 | `ruff` (lint + format), `mypy` | 빠른 통합 도구체인 |
| 패키징 | **PyInstaller (단일 EXE)** | 단일 파일 배포 — 일반 사용자 친화적 |
| 아이콘 | qtawesome (Font Awesome) | 라이선스 자유, 다크모드 친화 |
| **UI 언어** | **English only** | 단순화, 팀 내 다국가 사용자 대비 |
| **테마** | **Light / Dark + System** | 사용자 선택, Windows 시스템 테마 자동 감지 옵션 |

### 7.2 인터랙션 원칙

* **즉시성**: 스캔이 끝나기 전이라도 이미 완료된 폴더부터 트리에 반영(점진적 표시).
* **무중단**: 모든 무거운 작업은 워커 스레드. UI 블로킹 절대 금지.
* **명료성**: 크기는 사람이 읽기 좋은 단위(KB / MB / GB) + 정확 바이트 툴팁.
* **안전성**: 파괴적 작업(삭제/이동)은 반드시 확인 다이얼로그.

## 10. 위험 요소 (Risks)

| 위험 | 영향도 | 대응 |
|------|-------|------|
| 100만 파일에서 메모리 폭증 | 고 | 노드를 SQLite로 페이징, lazy-load TreeView 모델 |
| Windows long path(>260) 처리 | 중 | `\\?\` 프리픽스 사용, manifest에 longPathAware |
| PyInstaller 단일 EXE 시작 시간(2~5초) | 중 | 스플래시 스크린, `--onedir` 옵션도 빌드해 비교 |
| 권한 없는 폴더 무한 루프 / 크래시 | 고 | try/except + 화이트리스트, 순환 감지 |
| PySide6 LGPL 동적 링크 의무 | 중 | PyInstaller가 자동으로 동적 링크 유지 — 라이선스 고지 페이지 추가 |

## 11. 검수 기준 (Acceptance)

* [x] `C:\` 전체 스캔이 완료된다 (C:\Windows 스캔 완료 로그 확인, 2026-05-07).
* [x] 스캔 중에도 트리 스크롤/창 이동이 가능하다 (QRunnable 워커 분리 구현 완료).
* [x] 권한 없는 폴더 1개 이상이 포함된 경로에서 크래시 없이 끝난다 (`Cannot list directory` WARNING 후 계속 진행 확인).
* [x] 휴지통 삭제 → 트리에 즉시 반영된다 (`remove_node()` + `beginRemoveRows/endRemoveRows` 구현).
* [x] CSV / JSON 내보내기 결과가 생성된다 (exporters 구현, 단위 테스트 통과).
* [x] 단일 `tree-size.exe`가 Python 미설치 환경에서 실행된다 (81.8 MB, 2026-05-08 빌드 확인).
* [x] 라이트/다크 테마 전환 시 모든 위젯이 즉시 갱신된다 (SettingsDialog → themeChanged Signal 구현).
* [x] 스캔 후 트리뷰에 계층 구조가 표시된다 (DFS post-order 버그 수정, 2026-05-08).
